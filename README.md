## كيفية استخدام دفتر الملاحظات

1.  **افتح الدفتر في Google Colab:**
    *   **[انقر هنا لفتح دفتر التحليل الإحصائي في Google Colab](https://colab.research.google.com/github/YOUR_GITHUB_USERNAME/YOUR_REPOSITORY_NAME/blob/main/Statistical_Analysis_Notebook.ipynb)**
    *   *ملاحظة: يرجى استبدال `YOUR_GITHUB_USERNAME` و `YOUR_REPOSITORY_NAME` باسم مستخدم ومستودع GitHub الفعليين بمجرد تحميل هذا المشروع.*

2.  **احفظ نسخة:**
    *   بمجرد فتح الدفتر، انتقل إلى **File > Save a copy in Drive**. سيؤدي هذا إلى حفظ نسخة شخصية من الدفتر في Google Drive الخاص بك، مما يسمح لك بإجراء التغييرات وحفظها.

3.  **اتبع التعليمات:**
    *   اتبع التعليمات الموجودة داخل الدفتر. قم بتشغيل الخلايا بالترتيب عن طريق النقر على زر التشغيل (▶) لكل خلية.
    *   ستبدأ بتثبيت المكتبات، ثم تحميل ملف البيانات الخاص بك، وأخيرًا إجراء التحليلات التي تحتاجها.

-   **الإحصاءات الوصفية:** حساب المتوسط، الانحراف المعياري، الالتواء، والتفلطح.

-   **التحليل العاملي:** إجراء اختبارات كفاية العينة (KMO و Bartlett)، وحساب القيم الذاتية، واستخراج تشبعات العوامل.
