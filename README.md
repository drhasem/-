# منصة التحليل الإحصائي المتقدم

هذا هو تطبيق ويب لإجراء تحليلات إحصائية متقدمة، تم تطويره بواسطة الدكتور حاسم أحمد الجزار.

## نظرة عامة على البنية

يستخدم هذا التطبيق بنية العميل-الخادم:
- **الواجهة الأمامية (Frontend):** واجهة مستخدم ثابتة مبنية باستخدام HTML و CSS و JavaScript. توجد جميع ملفات الواجهة الأمامية في دليل `static/`.
- **الواجهة الخلفية (Backend):** واجهة برمجة تطبيقات (API) مبنية باستخدام Flask (Python) تقوم بجميع الحسابات الإحصائية. يوجد كود الواجهة الخلفية في `app.py`.

## الإعداد المحلي

1.  **المتطلبات الأساسية:**
    *   Python 3.8+
    *   `pip` (مدير حزم Python)

2.  **تثبيت التبعيات:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **تشغيل الخادم:**
    ```bash
    python app.py
    ```
    سيقوم هذا الأمر بتشغيل خادم تطوير محلي. يمكنك الوصول إلى التطبيق على `http://127.0.0.1:5001`.

## كيفية النشر (مُوصى به: Render)

**مهم:** لا يمكن نشر هذا التطبيق على أنه موقع ثابت. يتطلب بيئة يمكنها تشغيل خادم ويب Python. نوصي باستخدام **Render** لسهولة الاستخدام وخطتها المجانية.

### دليل النشر خطوة بخطوة على Render

1.  **إنشاء حساب:**
    *   انتقل إلى [render.com](https://render.com/) وأنشئ حسابًا جديدًا (يمكنك التسجيل باستخدام حساب GitHub الخاص بك لتبسيط العملية).

2.  **إنشاء خدمة ويب جديدة:**
    *   في لوحة تحكم Render، انقر فوق **New +** ثم حدد **Web Service**.
    *   اختر مستودع GitHub الخاص بك لهذا المشروع.

3.  **تكوين خدمة الويب:**
    *   **Name:** أعطِ تطبيقك اسمًا فريدًا (على سبيل المثال، `statistical-analysis-app`).
    *   **Region:** اختر منطقة قريبة منك.
    *   **Branch:** اتركها `main` أو اختر الفرع الذي تريد نشره.
    *   **Root Directory:** اتركها فارغة.
    *   **Runtime:** اختر **Python 3**.
    *   **Build Command:** `pip install -r requirements.txt`
    *   **Start Command:** `gunicorn --worker-class gevent --bind 0.0.0.0:10000 wsgi:app`
    *   **Instance Type:** اختر **Free**.

4.  **إنشاء ونشر:**
    *   انقر فوق **Create Web Service**.
    *   سيقوم Render تلقائيًا ببناء تطبيقك ونشره. يمكنك مشاهدة التقدم في سجلات النشر.
    *   بمجرد اكتمال النشر، سيتم تزويدك بعنوان URL عام لتطبيقك (على سبيل المثال، `https-statistical-analysis-app.onrender.com`).

هذا كل شيء! يجب أن يكون تطبيقك الآن مباشرًا ويعمل بشكل كامل.
